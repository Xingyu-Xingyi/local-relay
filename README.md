## 现在有什么（2026-11-12 写的）

`relay.py`：一个只用标准库的本地转发，做三件事

1. 把 method / path / 请求体 / 头（Host 和 Connection 除外）原样转给上游
2. 把上游的响应原样带回，不改状态码
3. 每次记一条 jsonl：时间、方法、路径、状态码、耗时、请求头（Authorization / X-Api-Key / Cookie 只留前六位）、响应头、响应前 400 字

状态码按两类分开记，别混成一句「失败了」：

- `rejected_by_upstream`：4xx，是上游在判定
- `link_error`：5xx 或连不上，是链路上出的事

**它不伪造凭据**：客户端带什么就转什么，一个头都没带就一个头都没带。上游要凭据就照样 401 回来。

`selftest.py`：起一个假上游（/ok 放行、其它 401），把三条路都走一遍，验透传、验分类、验凭据在日志里被遮住。跑一遍全过。
